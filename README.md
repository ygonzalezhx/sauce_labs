
# 🧪 Sauce Labs Testing Strategy & QA Artifacts

## Overview

This repository contains the end-to-end quality assurance (QA) documentation and testing strategy for the Sauce Labs application. 

The project covers the entire QA lifecycle: requirements analysis, test case documentation, execution and automation of assertions in Postman, and defect management.

---
## Scope of the project

**Test strategies**
* Manual testing
* Automated testing

**Test types**
* Functional testing
* Boundary Testing and Business Validation
* State Maintenance Testing (Persistence and Deletion)

---
## 🛠️ Tech stack and tools
* Excel / Markdown: Epic, User Stories, design matrix and test case identification.
* Visual Studio Code
* Playwright
* Typescript
